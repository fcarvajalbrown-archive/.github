# Felipe Carvajal Archive

I have built more projects than I can maintain at once. I keep the ones I have finished or set aside here, with their code and history intact.

Repositories here are archived and read-only — no issues, no pull requests, no further commits. A repository keeps the visibility it had before the move: public stays public, private stays private. Moving a repository here does not change its license or its git history, but GitHub Pages sites do not carry over; a Pages URL that worked before the move will not redirect.

The projects I am actively working on are on [my GitHub profile](https://github.com/fcarvajalbrown).
